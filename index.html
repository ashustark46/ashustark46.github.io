A bit about me.

I've been writing backend code for 4 years, all at Genpact. Most of that time was on Morgan Stanley's Thunderhead — the platform they use to process stock and derivative trades. I built Spring Boot services, fixed slow MySQL queries, and set up automated tests that cut a lot of manual QA work.

I also spent time on Click Therapeutics, a company that makes health apps used by real patients. That work was on the frontend, but I stayed close to the API layer — and honestly, I was always more drawn to the Java side of things.

I'm most comfortable with Java, Spring Boot, JPA, and MySQL. I care about code that's easy to read and hard to break. And I enjoy mentoring newer engineers — that turned out to be one of my favourite parts of the job.

I've been between roles since Dec 2025. In the meantime, I've been building the backend for a friend's early-stage LMS startup — real Spring Boot code with PostgreSQL, Spring Security, and JWT for role-based auth across four user types. On the side, I'm also picking up Spring AI so I can add generative-AI features to Java services without switching stacks. See what I'm working on.
